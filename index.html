Before you start

  • Use a recent Chrome, Edge, or Firefox. The first load of each app downloads the Python runtime (~10 MB) and may take a few seconds; after that it's cached.
  • Your code and progress are kept in your browser's local storage - they stay on the machine you used, and clearing site data will erase them.
  • None of this is graded. Experiment freely.
